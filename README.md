# weekly-report skill

Claude Code 用の週報作成スキルと、コピーボタン付きHTMLを生成するスクリプトのセットです。

毎週の週報を、前回分との差分指示だけで更新できるようにすることを目的としています。
生成したHTMLをブラウザで開き、コピーボタンで全文をクリップボードへコピーして、社内の報告フォームやチャットへ貼り付ける運用を想定しています。

## 構成

| パス | 内容 |
| --- | --- |
| `skills/weekly-report/SKILL.md` | 週報作成スキル本体。Claude Code のスキルとして配置する |
| `scripts/build_report.py` | 週報本文のテキストからHTMLを生成するスクリプト |
| `templates/report.html.tpl` | 生成されるHTMLのテンプレート |
| `examples/weekly-report-sample.txt` | 週報本文のサンプル |
| `docs/CLAUDE.md.example` | プロジェクト単位の指示ファイルの記載例 |

## 導入手順

1. スキルを配置します。

   ```sh
   mkdir -p ~/.claude/skills
   cp -r skills/weekly-report ~/.claude/skills/
   ```

   プロジェクト単位で使う場合は、対象プロジェクト直下の `.claude/skills/` へ配置します。

2. `skills/weekly-report/SKILL.md` を開き、環境に合わせて次の2点を書き換えます。

   - 「週報ファイルの保存先」の `<週報ディレクトリ>` を実際のパスへ置き換える
   - 「利用者の役割（文脈情報）」に所属・担当・立場を記載する

3. 必要に応じて `docs/CLAUDE.md.example` を参考に、週報ディレクトリへ `CLAUDE.md` を置きます。

4. Claude Code で `/weekly-report` を実行します。

## 使い方

### スキルから使う

`/weekly-report` を実行し、その週の実施内容をチャットに貼り付けます。
スキルが対象期間（今週の月〜金、翌週の月〜金）を自動で確定し、所定フォーマットの週報を作成してHTMLを出力します。

2回目以降は差分だけを伝えれば更新されます。

```
A案件は完了したので削除
B案件に〇〇のレビュー対応を追加
トピックスを△△に変更
```

### スクリプト単体で使う

週報本文のテキストファイルからHTMLを生成します。
対象期間は実行日から自動計算されます。

```sh
python3 scripts/build_report.py -i examples/weekly-report-sample.txt -o 週報.html --open
```

主なオプションです。

| オプション | 内容 |
| --- | --- |
| `-i, --input` | 週報本文のテキストファイル。`-` で標準入力 |
| `-o, --output` | 出力するHTMLファイル |
| `--period` | ヘッダに表示する対象期間を明示する。省略時は自動計算 |
| `--date` | 自動計算の基準日（`YYYY-MM-DD`）。省略時は今日 |
| `--open` | 生成後にブラウザで開く（macOS の `open`） |

## 生成されるHTMLの機能

週報の本文を読みやすい体裁で表示します。
右上の「コピー」ボタンで全文をクリップボードへコピーします。
`navigator.clipboard` が使えない環境では、範囲選択して `document.execCommand('copy')` する代替処理に切り替わります。
コピー後はボタンが「コピー完了」に変わり、画面下に「コピーしました」とトースト表示して2秒後に戻ります。

## 出力フォーマット

```
【トピックス】

・今週一週間のポイントを一言で

【作業内容】

■ 案件A
・作業内容を箇条書きで

【今後の作業予定】

■ 案件A
・作業予定を箇条書きで

【課題】

・案件・作業を進める上で感じた課題

【連絡事項】

・休暇の予定など前もってわかっていること

【コメント】

・案件・作業に関連していなくても伝えたいこと
```

## 注意

生成した週報には業務情報が含まれます。
出力先のHTMLはリポジトリへコミットしないでください（`.gitignore` で `週報.html` を除外しています）。

## 動作環境

macOS、Python 3.9 以降（標準ライブラリのみ使用）。
`--open` オプションは macOS の `open` コマンドを使用します。
